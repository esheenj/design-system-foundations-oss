# Responsible disclosure

This repository is a small offline reference implementation with no hosted backend or production authentication.

If you discover a vulnerability that could affect users, **do not open a public issue containing exploit details, private data or credentials**. Contact the maintainer privately using GitHub's private vulnerability reporting feature when enabled, or another independently verified private contact channel. Avoid sending sensitive information until a secure contact method has been confirmed.

For non-sensitive behavior problems, use the public issue templates. This document is not a claim of a complete security program or guarantee of a response time.
